# 柳比歇夫时间记录（极简版 · 五行分类）

在手机上用最极简的方式记录"我正在做的事情用了多少时间"。

- **交互**：输入"在做什么"即开始计时（**不卡分类**）——本地规则按"本质意图"自动归类，认不出记为"未分类"，事后随时可改；**计时中状态卡背景显示五行分类色**
- **分类体系**：五行 · 十四行为标签（取象比类、直击意图），**纯本地规则，不联网、不需要任何 API Key，谁拿到都能用**
- **统计**：日 / 周 / 月饼图（五行配色）+ 图例；**一键导出明细表（Markdown），复制粘贴给你自己的 AI 即可生成饼图/分析**
- **可重分类**：每一条记录都可以随时重新分类
- **数据**：仅保存在手机浏览器本地（IndexedDB）
- **形态**：单页 PWA，手机浏览器访问即可使用

## 启动（在麒麟电脑上）

```bash
cd lyubishchev
node server.js 8000
```

查看电脑局域网 IP：

```bash
hostname -I
```

然后在**手机浏览器**打开：`http://<电脑局域网IP>:8000`

> 若无法访问，检查麒麟防火墙是否放行 8000 端口：
> `sudo ufw allow 8000`（或 `firewall-cmd --add-port=8000/tcp`）

### 分类知识库（核心规则 · 取象比类，直击意图）

| 五行 | 颜色 | 行为标签 | 地支 |
|---|---|---|---|
| 木 | #2ECC71 | 攻坚开拓 / 学习精进 | 寅 / 卯 |
| 火 | #E74C3C | 表达创作 / 协作共赢 / 竞技爆发 | 巳 / 午 / 戌 |
| 土 | #F39C12 | 睡眠修复 / 健身滋养 / 日常运维 / 整理归档 | 未 / 辰 / 戌 / 丑 |
| 金 | #BDC3C7 | 精炼打磨 / 收尾结算 | 申 / 酉 |
| 水 | #2980B9 | 情感社交 / 冥想放空 / 复盘谋略 | 亥 / 亥 / 子 |

**本质归类铁律**（按动机判别，忽略表面动作，已内置）：
1. **睡眠/午休/打盹** → 承载修复 → 必归「睡眠修复」（土）
2. **变美/打扮/化妆/穿搭** → 向外展现自我 → 必归「表达创作」（火）
3. **看风景/发呆/听纯音乐** → 意识自由漂流 → 必归「冥想放空」（水）
4. **运动**：健康保持/日常锻炼（慢跑、健身、瑜伽）→「健身滋养」（土）；竞技突破/比赛/冲刺 →「竞技爆发」（火）
5. **社交**：业务推进/团队协作/签约（开会、谈客户）→「协作共赢」（火）；情感链接/闲聊（刷朋友圈、唠嗑）→「情感社交」（水）
6. **竞技爆发识别**：输入含 挑战/限时/冲刺/立刻/马上/赶紧/赶工/倒计时 等时间压力词，无论表面动作（写作业、写代码、做家务）→ 必归「竞技爆发」（火）；但"未来计划/准备"（如"计划下个月挑战全马"）不触发，按实际意图归类

### 关键行为

- **先录入，计入时间**：输入文字点"开始"立即计时，分类识别**从不打断你**——认不出就记为"未分类"（❓灰色），事后在统计页点击该记录重分类即可
- **导出明细表**：统计页有 **导出今日明细表 / 导出本周明细表（周一起）/ 导出本月明细表（1号起）** 三个按钮，点击生成 Markdown 文档（按行为汇总 + 明细）保存在手机下载目录，直接提交给任意 AI（如 DeepSeek/ChatGPT）说"帮我做成饼图"即可
- **重新分类**：统计页时间线点击任意一条记录 → 弹窗选新分类；计时中点击状态卡上的分类 chip 也可修改
- **开始/停止模式**：计时中其他分类按钮会锁定（置灰），必须先停止当前计时才能开始别的——保证同一时刻只有一条时间记录
- **中断恢复**：关闭浏览器或刷新页面后，进行中的计时会继续（重新打开仍在计时）
- **遗忘提醒**：计时中超过设定时间没有操作，会弹出"还在进行吗？"横幅（**睡眠修复类不提醒**——睡觉时提醒无意义）
- **超长提醒**：单次计时超过设定时长（默认 4 小时）会提醒，防止忘记停止（睡眠修复类同样不提醒）
- **僵尸会话**：超过 24 小时未结束的计时会在下次打开时自动关闭

### 修改分类规则

所有关键词都集中在 `classify-rules.js` 的 `CATEGORIES` 里。分类**每次从规则文件读取**（不缓存），改完刷新手机页面即生效，不需要重启服务器、不需要清数据。

### 数据备份

设置 → 数据 → **导出 JSON** 可下载完整备份（记录 + 设置），换手机或清浏览器时用 **导入 JSON** 恢复。CSV（含 行为标签/五行/地支/备注 列）可导入 Excel 做周报月报分析。

## 部署到公网（让任何人都能用）

应用是**纯静态**的（分类规则在浏览器本地跑、数据存在各人自己的手机里），所以不需要你的电脑当服务器——随便一个免费静态托管就能让全世界访问。**每个人用自己的浏览器打开，各记各的，互不干扰。**

### 方式一：GitHub Pages（推荐，免费 HTTPS）

1. 登录 github.com → **New repository**，名字填 `lyubishchev`，选 **Public**，不要勾选"初始化 README"（项目里已有）
2. 本项目已配置好远端（用户名 `cherrysash`），在项目目录直接推送：

```bash
cd lyubishchev
git push -u origin main
```

> 首次推送会要求登录：用户名填 `cherrysash`，**密码处填 Personal Access Token**（不是登录密码）——
> github.com → Settings → Developer settings → Personal access tokens → Generate new token，勾选 `repo` 权限，生成后复制粘贴。

3. 仓库 **Settings → Pages** → Source 选 `main` 分支、根目录 → Save
4. 等 1~2 分钟，访问：`https://cherrysash.github.io/lyubishchev/`

> 更新：`git add -A && git commit -m "更新" && git push`，1 分钟后刷新生效。
>
> 国内直连 GitHub 可能较慢或超时，推送失败可重试或挂代理（`git config http.proxy http://代理地址:端口`）。

### 方式二：Netlify Drop（不用 git，拖拽即用）

打开 `app.netlify.com/drop`，把整个 `lyubishchev` 文件夹**拖进去**，立刻得到一个公开 HTTPS 地址。改完文件再拖一次就更新。最简单，适合不折腾 git。

### 方式三：Cloudflare Pages / Vercel

同样免费，连接你的 GitHub 仓库后自动构建发布，国内访问速度通常也不错。

### 公网部署的额外好处

- **HTTPS**：浏览器允许 Service Worker 运行 → 手机上可"添加到主屏幕"变成 App，**离线也能用**
- 数据永远在用户自己的设备上，不需要注册、不会泄露

## 关于离线安装（PWA）

浏览器安全策略要求 Service Worker 只能在 **HTTPS 或 localhost** 下运行。
- 局域网 **http** 访问：功能完整可用，只是没有离线缓存、也没有"安装为应用"提示
- 想要"添加到主屏幕成为 App + 离线可用"：需要 HTTPS（自签名证书会有证书警告，或用内网域名证书）

数据在两种情况下都只存在手机浏览器本地，互不影响。
